BETÃO SCORES v13 — ПОЛНЫЙ САЙТ ДЛЯ НОВОГО ТЕСТОВОГО GITHUB-РЕПОЗИТОРИЯ
========================================================================

ЧТО ИСПРАВЛЕНО
- Рекламное видео v13 показывается поверх ВСЕГО сайта сразу при открытии index.html.
- Географическая проверка в ТЕСТОВОЙ версии отключена: реклама видна из любой страны.
- Пустая рекламная ссылка больше не мешает показу рекламы (но переход по нажатию
  заработает только после заполнения destinationUrl).
- Кнопка × закрывает рекламу. После обновления страницы она появляется снова.
- Ролик 720x960 H.264, без звука, playsinline; при блокировке автовоспроизведения
  показывается постер. На iPhone реальное поведение нужно проверить вручную.
- Удалён файл CNAME, чтобы тестовый репозиторий НЕ перехватил betaoscores.com.

КАК ЗАГРУЗИТЬ В НОВЫЙ РЕПОЗИТОРИЙ
1. На GitHub нажмите + -> New repository. Например: bettao-v13-test.
2. Выберите Public, затем Create repository.
3. Распакуйте ЭТОТ ZIP. Нельзя загружать ZIP как один файл в GitHub Pages.
4. В новом репозитории нажмите Add file -> Upload files.
5. Перетащите ФАЙЛЫ И ПАПКИ ИЗНУТРИ распакованного архива.
   В корне репозитория должен лежать index.html, а не вложенная папка.
   Если GitHub на телефоне не даёт загрузить папки, сначала загрузите корневые
   файлы, затем отдельно создайте папки scripts и .github/workflows и добавьте
   их содержимое. Для показа рекламы эти две папки не обязательны.
6. Нажмите Commit changes.
7. Settings -> Pages -> Build and deployment -> Deploy from a branch.
   Branch: main, Folder: /(root), Save.
8. Дождитесь появления адреса GitHub Pages. Например:
   https://ВАШ-ЛОГИН.github.io/bettao-v13-test/
9. Откройте ссылку: сразу появится полноэкранная реклама поверх сайта.
   Нажмите × — откроется обычный сайт. Обновите страницу — реклама снова появится.

КУДА ВСТАВИТЬ ССЫЛКУ ПОСЛЕ НАЖАТИЯ НА БАННЕР
Откройте geo-ad-config.js и найдите:
    destinationUrl: '',
Замените на, например:
    destinationUrl: 'https://example.com/landing',
Вместо example.com/landing вставьте ваш реальный HTTPS-адрес.
Затем Commit changes. Нажатие на видео откроет указанный адрес.
Если ссылка пустая, видео видно, но клик по рекламе ничего не открывает.
Кнопка × всегда остаётся доступной.

КОГДА ЗАХОТИТЕ ВЕРНУТЬ ОГРАНИЧЕНИЕ ТОЛЬКО ДЛЯ БРАЗИЛИИ
В geo-ad-config.js измените:
    testMode: false,
Тогда реклама появится только после подтверждения бразильского IP и только
при непустой HTTPS-ссылке. На тестовом сайте testMode: true.

ВАЖНО
- В этой тестовой сборке реклама показывается из любой страны — НЕ публикуйте
  её как финальную версию, если требуется географическое ограничение.
- Нельзя одновременно назначать betaoscores.com двум GitHub Pages репозиториям.
- Проверяйте законность рекламируемого продукта, права на изображения и
  утверждения о призах перед реальной публикацией.
