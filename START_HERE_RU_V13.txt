BETÃO SCORES — ВОЗВРАТ РЕКЛАМЫ V13 И УСТАНОВКА НА GITHUB
========================================================

В этом архиве ПОЛНЫЙ САЙТ версии 13: оригинальные видео,
дизайн, анимация барабанов и рекламный постер v13.
Изменено только поведение повторного показа:
закрытие не сохраняется между загрузками страницы.

ШАГ 1. УКАЗАТЬ ССЫЛКУ РЕКЛАМОДАТЕЛЯ
----------------------------------
В корне архива найдите geo-ad-config.js.
Откройте его в текстовом редакторе.
Найдите строку:
  destinationUrl: '',
Замените, например, на:
  destinationUrl: 'https://example.com/your-landing-page',

ВАЖНО: используйте настоящий HTTPS-адрес, который принадлежит
рекламодателю. Сохраните одинарные кавычки и запятую в конце.
Адрес в примере НЕ является действующей ссылкой на рекламодателя.
Пока destinationUrl пустой, реклама на основном сайте НЕ ПОЯВИТСЯ.

ШАГ 2. ЗАГРУЗИТЬ САЙТ НА GITHUB PAGES
------------------------------------
1. Скачайте ZIP и распакуйте его (не загружайте ZIP как один файл).
2. Откройте GitHub и репозиторий bettaoscores, из которого
   публикуется betaoscores.com. Убедитесь, что выбрана ветка
   и папка, которые указаны в Settings -> Pages.
3. Сначала сделайте резервную копию текущего репозитория:
   Code -> Download ZIP.
4. В корне репозитория выберите Add file -> Upload files.
5. Перетащите ФАЙЛЫ И ПАПКИ ИЗНУТРИ распакованного архива.
   index.html, geo-ad-config.js, geo-ad.js, geo-ad.css,
   betao-premium-ad.mp4 и betao-premium-ad-poster.webp
   должны находиться в корне сайта, рядом друг с другом.
   scripts/fetch_matches.py должен быть в scripts/.
   .github/workflows/refresh-matches.yml должен быть в .github/workflows/.
   Если GitHub в браузере не позволяет корректно загрузить вложенные
   папки, откройте их в репозитории и загрузите файлы отдельно.
6. Внизу нажмите Commit changes. Подождите публикации Pages.
7. НЕ удаляйте папку data/ и другие файлы, которых нет в архиве.

ШАГ 3. ПРОВЕРКА
--------------
1. Откройте https://betaoscores.com/BETAO_AD_PREVIEW.html —
   это только просмотр оригинального видео v13 без проверки страны.
2. Для проверки настоящего рекламного окна откройте главную страницу
   с бразильского IP (или временно с VPN BR) и с заполненным HTTPS URL.
   Для посетителей вне Бразилии реклама не показывается.
3. Нажмите X: реклама закрывается. Обновите страницу: при
   подтверждённом BR IP реклама сможет показаться снова.
4. Нажмите на сам баннер: должен открыться destinationUrl.
5. Если старая версия осталась, сделайте полное обновление страницы
   или очистите кэш WebView/браузера.

ПОВТОРНЫЙ ПОКАЗ В IOS
--------------------
Закрытие больше не записывается в sessionStorage.
При НОВОЙ загрузке главной страницы рекламное окно снова может
появиться. Но если iOS-приложение держит тот же WKWebView в памяти
между сворачиванием и открытием, JavaScript не узнает о новом запуске.
Для гарантированного показа при каждом новом запуске iOS-приложение
должно перезагружать главную страницу при новом запуске/создании WebView.
Не нужно принудительно перезагружать страницу при каждом возвращении
из фона — это может раздражать пользователя.

ГДЕ МЕНЯТЬ ССЫЛКУ ПОЗЖЕ БЕЗ ПЕРЕЗАГРУЗКИ САЙТА
----------------------------------------------
GitHub -> bettaoscores -> geo-ad-config.js -> Edit (карандаш) ->
измените destinationUrl -> Commit changes.
Остальные файлы трогать не нужно.

Оригинальный креатив v13 содержит изображения/утверждения о

не заменяет проверку возраста и разрешений.
