BETTAO SCORES — FULL WEBSITE v12 + BRAZIL-ONLY AD
================================================

В архиве собран сайт из v11 со всеми предыдущими обновлениями, плюс полноэкранная реклама только для Бразилии. Добавлены отсутствовавшие в предыдущем архиве premium.css, premium.js, premium-preview.webp.

ЧТО НУЖНО СДЕЛАТЬ
1. Распакуйте ZIP.
2. Откройте файл geo-ad-config.js в TextEdit / VS Code.
3. В строке destinationUrl: '' впишите РЕАЛЬНУЮ ссылку, например:
   destinationUrl: 'https://your-advertiser.example/landing',
   Пока ссылка пустая, рекламное окно НЕ ПОЯВЛЯЕТСЯ. Это защита от неработающей кнопки.
4. bannerImage: 'promo-banner.webp' — картинка для компьютера;
   mobileBannerImage: 'promo-mobile.webp' — картинка для телефона.
   Можно заменить эти имена на свои изображения, загруженные в репозиторий.
5. Загрузите файлы из архива в GitHub в те же папки, как в архиве.
   scripts/fetch_matches.py -> scripts/fetch_matches.py
   .github/workflows/refresh-matches.yml -> .github/workflows/refresh-matches.yml
   НЕ удаляйте существующую папку data/ или другие файлы, которых нет в архиве.
6. После публикации откройте сайт из Бразилии или через бразильское VPN-соединение для проверки.

КАК ЭТО РАБОТАЕТ
- При открытии главной страницы браузер проверяет страну IP через GeoJS;
  если GeoJS не работает — через ipapi.co.
- Если страна точно BR и указана HTTPS-ссылка, показывается рекламный экран.
- Пользователь может закрыть рекламу кнопкой X или клавишей Escape.
- Нажатие на баннер или JOGAR AGORA открывает destinationUrl.
- По умолчанию открытие в текущем окне (лучше для WebView).
- После закрытия окно больше не показывается в той же вкладке до завершения сессии.
- Если страна не определилась, реклама НЕ показывается.
- Определение по IP не является гарантированной защитой: VPN, прокси, мобильные операторы могут менять определяемую страну.
- При использовании азартной рекламы необходимы разрешения, возрастные ограничения и соответствие законам целевой страны и правилам Apple.
- Текст Privacy обновлён с описанием запросов к GeoJS / ipapi.co.

ВАЖНО: ДЛЯ БРАЗИЛЬСКИХ ПОСЕТИТЕЛЕЙ РЕКЛАМА АКТИВИРУЕТСЯ ТОЛЬКО ПОСЛЕ ТОГО, КАК ВЫ ВСТАВИТЕ HTTPS-ССЫЛКУ.
